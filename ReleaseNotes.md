## 1.0.0-alpha.1

GrabKit's first release: automated website and App Store screenshots for Apple-platform apps, taken from a UI test. Each shot is named for the appearance it was actually captured in and exported from the `.xcresult` as `NN-slug-light.png` and `NN-slug-dark.png`. It requires Swift 6.4 (Xcode 27.2) and is an alpha, so the API may change before 1.0.0.

* Add GrabSupport, the app side: `GrabLaunchArguments` (the `-<Prefix>Screenshots YES` / `-<Prefix>Appearance light|dark` contract and the `<PREFIX>_SCREENSHOT_APPEARANCES` key), `GrabAppearance`, and `GrabWindowSizer`, which pins a SwiftUI window to a fixed content size on macOS by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
* Add `GrabLaunchDecision`, which decides every launch at runtime and fails closed. A `.Screenshots` build launched with the flag runs on demo data, one launched without it quits with `exit` (no crash dialog), and any other build runs live. There is no compile gate by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
* Add GrabTesting, the UI test side: `GrabScreen` and `GrabRunner` launch a fresh copy per appearance, drive it to the screen, switch the device appearance so menus and sheets match, refuse to shoot over a "quit unexpectedly" dialog, and attach the PNGs named by `GrabNaming` from the detected appearance by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
* Add `GrabTarget`, which captures a window, or a screen capture cropped to the window plus `extras` (menu bar titles, sheets). With `capturesScreen` it does the same for a context menu over the window by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
* Add `GrabImage`, `GrabCrop` and `GrabAppearanceDetector`: PNG coding through ImageIO, tagged with the scale's DPI (144 at 2x), pixel-space crops, and light-or-dark detection by Rec. 709 luminance. Also add `GrabFixture`, `GrabError` and the `XCUIElement` helpers (`waitToExist`, `waitUntil`, `waitForStableFrame`, `waitForSize`, `parkPointer`) by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
* Add `grab-export [--keep-others] <result bundle> <output folder>`, which copies only the runner-named PNGs out of a run's `.xcresult` through `xcresulttool`. By default it empties the output folder first. `--keep-others` replaces only the files the run exports by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
* Support iOS 16, watchOS 9, tvOS 16, visionOS 1, Mac Catalyst 16 and Linux alongside macOS 27, with `#if` guards. On UIKit platforms `GrabAppearance` gives `userInterfaceStyle` and `apply(to:)` for a `UIWindow`; `GrabWindowSizer` is macOS only; `parkPointer()` does nothing on tvOS, visionOS and watchOS; the runner can't switch the device appearance on watchOS; on Linux `GrabImage`, the `CGImage` detector and the XCUITest runner are compiled out and the launch refusal logs to stderr instead of OSLog; `grab-export` builds everywhere but does its job only on macOS
* CI: build and test with `brightdigit/swift-build` on Ubuntu (Swift 6.4 noble, plus jammy on the full matrix) and on Xcode 27.2 for macOS and iOS, plus watchOS, tvOS and visionOS on PRs into `main` or a semver branch; build the DocC catalogs and lint by @leogdion in https://github.com/brightdigit/GrabKit/pull/1
